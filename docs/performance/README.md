# 拖动与缩放性能评估

2026-10-28，基线 fd78cba。评估 Popup、Modal、Drawer，使用真实 Ant Design Vue 表单。所有数据来自同机 Chrome headless、1100×800、Vite 开发模式、CDP 4 倍 CPU 降速；不能等同生产构建或所有设备的帧率保证。

## 发现与处理

- 高频 pointermove 原来逐次写响应式几何并触发事件，微任务间隔足以造成同一帧重复渲染。现在保留逐样本边界计算，仅将视觉提交与移动事件合并到 requestAnimationFrame；结束同步刷新，避免丢失最终尺寸。相同几何不重复发出移动事件。
- 拖动原来每次改 left/top，产生布局。现在仅在拖动期间使用 translate3d，结束后清理并写回最终位置；缩放需要重排内容，仍直接改宽高。
- Demo 诊断文本原来跟随每次移动更新，增加了交互开销。现在独立以 10Hz 采样，业务表单父组件不订阅高频几何。

## 实际鼠标交互

每个场景执行两次，每次 120 个 Playwright mouse.move 样本。下表为两次的平均值，单位 ms；TaskDuration 为整个交互累计主线程时间，不是单帧耗时。包含 Demo 的诊断和开发模式开销。

| 场景 | 主线程时间：前 → 后 | Layout：前 → 后 |
| --- | --- | --- |
| Popup 拖动 | 3862.50 → 3704.85 | 154.78 → 72.37 |
| Popup 缩放 | 4027.93 → 3891.02 | 304.94 → 251.27 |
| Modal 拖动 | 1511.54 → 1258.56 | 23.89 → 0.90 |
| Modal 缩放 | 1595.31 → 1579.55 | 108.28 → 105.39 |
| Drawer 拖动 | 1929.62 → 1411.79 | 80.77 → 20.71 |
| Drawer 缩放 | 2895.70 → 2300.17 | 280.54 → 184.33 |

Modal 的原始交互已经没有长任务，优化后仍然没有；最终 Drawer 两类交互也均没有长任务。Popup 的复杂 Demo 在降速环境仍出现 16.9–33.4ms 的 p95 帧间隔及长任务，不能声称全部场景达到 60fps；其中拖动长任务次数没有改善。该数据有运行噪声，仅两次重复，不作统计显著性结论。

## 高频压力场景

另外合成 60 帧、每帧 16 个 pointermove 样本，样本间让出微任务，共 960 个输入。它用于验证过量输入时的批处理，不代表普通鼠标实际频率。每项仅执行一次。

| Popup 场景 | 主线程时间 ms：前 → 后 | 面板子树更新：前 → 后 | p95 帧间隔 ms：前 → 后 | 长任务数：前 → 后 |
| --- | --- | --- | --- | --- |
| 拖动 | 16859.02 → 1580.31（约 -90.6%） | 954 → 61 | 333.4 → 33.5 | 60 → 1 |
| 缩放 | 17185.68 → 2143.35（约 -87.5%） | 946 → 61 | 350.2 → 50.0 | 60 → 2 |

更新统计来自面板 DOM 所属 Vue Transition 实例的 updated hook（原始字段名 coreUpdates），是子树视觉提交的代理指标，不是核心组件自身的完整 render 计数。原始数据： [基线](./before.json)、[仅帧合并阶段](./after-frame-batching.json)、[最终结果](./after.json)。不能把压力场景的百分比套用于普通交互。

## 复测

先启动 `npm run dev -- --port 5187 --strictPort`，另一个终端运行：

```sh
npm run bench:interaction -- --label current --out docs/performance/current.json
```

可使用 `--cpu 1 --repeat 5` 检查无降速场景，也可用 `--url` 指向其他构建。比较时保持浏览器、构建模式、窗口和后台负载一致。报告记录 rAF 间隔、超过 50ms 的长任务、CDP Task/Script/LayoutDuration、Vue 子树/诊断/父级更新数。浏览器自动化与采样本身也有开销。

单元和真实浏览器回归另外验证：同帧合并、边界超限后立即反向、pointerup/pointercancel 刷新最终值、拖动 transform 清理和最终视口坐标。尚未覆盖 Firefox/WebKit、移动设备及生产环境的大型业务表单性能。
